# 机芯透视展示系统

面向机械表品牌的浏览器端机芯 3D 透视展示:无需拍视频,客户直接在网页里看透底后盖下的机芯运转,换夹板打磨方案即时预览。

**技术栈:TypeScript + WebGPU(WGSL)+ Vite,零运行时依赖。**

## 运行

```bash
npm install
npm run dev      # 开发,默认 http://localhost:5173
npm run build    # 类型检查 + 生产构建(dist/)
```

需要支持 WebGPU 的浏览器(Chrome/Edge 113+、Safari 18+)。不支持时「展示」页会给出引导提示,其余页面不受影响。

## 页面与功能

| 页面 | 功能 |
|---|---|
| 机芯列表 | 方案增删改、复制、设为当前;localStorage 持久化;单个/全部导出 JSON、导入 JSON |
| 轮系编辑 | 齿轮按模数+齿数参数化;传动比以秒轮为锚点自动推算(**秒针一圈正好 60 秒**);显示每级 rpm/周期/增速比/转向;摆频 21600/28800 切换;轮系推算摆频与设定摆频一致性校验并给出齿数建议 |
| 打磨装饰 | 日内瓦波纹(宽度/角度)、珍珠圆点纹(直径)、直线/环形拉丝、镜面抛光、倒角抛光、各向异性强度、蓝钢螺丝、红宝石轴承、表镜反光 |
| 展示 | WebGPU 3D 透视:拖动旋转、滚轮缩放;慢放 1×/0.2×/0.05×、暂停;点击齿轮显示模数/齿数/转速;截图(自动叠加机芯参数);走时精度 HUD |
| 设置 | WebGPU 状态检测、MSAA、渲染分辨率、走时精度 10 秒自检、数据备份/清空 |

## 两项硬指标的实现

### 1. 走时精度:10 分钟误差 < 0.1 秒

- 模拟时间 = `performance.now()` 单调时钟间隔 × 倍率直接累加(`src/sim.ts`),**不做帧计数**——掉帧、后台标签页挂起都不产生误差;
- 所有轮系角度是模拟时间的**解析函数** `θ(t)=2π·ω·t`,不逐步积分,没有数值漂移;
- 秒轮角速度锚定 `-1/60 rev/s`,其余轮由齿数比推出,秒针 60.000s/圈是构造保证而非调出来的;
- 「设置」页内置实测:对比 `performance.now()` 与系统时钟,推算 10 分钟误差(本机实测约 30ms,主要是 `Date.now` 毫秒取整噪声)。

### 2. 拉丝反光转动不闪

- 拉丝/日内瓦纹/珍珠纹全部在**物体局部空间**解析计算,切线方向由几何位置导出,随零件一起旋转——高光图案与零件刚性绑定;
- 各向异性高光用 Kajiya-Kay 解析模型,**无噪声贴图、无逐帧随机量**;
- 粗糙度下限钳制 + 4× MSAA,消除边缘和高光锯齿闪烁。

## 渲染架构

```
机芯场景(MSAA 离屏) → resolve 到纹理 → 全屏合成 → 蓝宝石表镜(薄壳折射采样 + 菲涅尔反光)
```

- 齿轮/夹板/游丝/摆轮全部程序化生成网格(`src/geometry.ts`),模数、齿数、齿轴直接决定几何;
- 材质在 WGSL 中实现:金属 BRDF + 各向异性拉丝、日内瓦波纹、珍珠纹、倒角强制镜面、蓝钢回火色(视角相关)、红宝石透光、表镜折射;
- 摆轮按 `vph/7200` Hz 简谐摆动,擒纵叉跟随节拍,游丝同步呼吸。

## 目录

```
src/
  types.ts      数据模型(机芯/齿轮/打磨配置)
  store.ts      localStorage 持久化 + 导入导出
  train.ts      轮系传动比计算、自动布局、默认机芯
  sim.ts        单调时钟 + 摆轮/擒纵运动学
  geometry.ts   程序化网格(齿轮、夹板、游丝、表镜…)
  scene.ts      机芯配置 → 渲染场景
  shaders.ts    WGSL(材质/合成/表镜)
  renderer.ts   WebGPU 渲染器(离屏 MSAA、拾取、截图)
  ui/           五个页面
  dev/wgslCheck.ts  开发期着色器语法自检(控制台调用)
```
